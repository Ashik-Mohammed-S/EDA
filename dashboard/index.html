WHAT IS BEING MEASURED

Definitions before conclusions.

Interpretation boundaries

This workspace describes historical data. It does not estimate causal effects, validate a prediction model, recommend lending eligibility or establish campaign uplift. Protected-attribute differences are descriptive audit views, not individual decision rules.

Wilson intervals assume a binomial sampling model; they do not account for repeated measurements, selection, confounding or multiple comparisons. Numeric outliers are flagged using the full-cohort 1.5 × IQR rule, not removed. Standard deviations use sample variance.

The dashboard ships aggregate stratum tables, variable bins and statistics. It contains no individual record identifiers. Fixed bin boundaries and category grouping are computed on the full analyzed dataset, so selected cohorts remain comparable.

Both projects preserve their earlier walkthroughs under historical/. The expanded current notebook and scripts regenerate the source audit, target tables, numerical comparisons, correlation matrices, charts and this dashboard artifact.
